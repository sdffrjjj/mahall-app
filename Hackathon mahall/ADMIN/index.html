Google Firebase Step-by-Step Setup Instructions

1 Create Firebase Project

Visit Firebase Console, click "Add project", name it (e.g. noorul-huda-mahall), and enable Cloud Firestore in your preferred region.

2 Register Web Application

In Project Settings -> General -> "Your apps", click the Web icon (</>). Copy the generated firebaseConfig snippet and paste it into the Auto-Detect box above.

3 Enable Authentication & Rules

In Firebase Console -> Build -> Authentication, enable "Email/Password". In Cloud Firestore -> Rules, paste the security rules provided in this repository for multi-tenant isolation.
